# ระบบลงทะเบียนและบันทึกภาพใบหน้าสำหรับสร้าง Dataset (Google Drive Storage)

ระบบบันทึกภาพใบหน้า 12 ท่าทางผ่านเว็บเบราว์เซอร์บนมือถือหรือคอมพิวเตอร์ และส่งภาพดิบ (Raw Images) บันทึกแยกโฟลเดอร์ตามชื่อคนลงใน **Google Drive** ของคุณโดยอัตโนมัติ

---

## 🌟 จุดเด่นของระบบ

1. **ไม่ใช้เซิร์ฟเวอร์ (Serverless):** รันฟรี 100% บน Google Apps Script ไม่ต้องเปิดคอมทิ้งไว้
2. **เพื่อนไม่ต้องลงแอป:** ส่งลิงก์เข้า LINE, Messenger หรือแชร์ QR Code ให้เพื่อนกดเปิดกล้องหน้าบน Safari หรือ Chrome ได้ทันที
3. **พื้นหลังสีขาวส่องหน้า:** หน้าจอเปิดพื้นหลังสีขาวเต็มจอ (`#FFFFFF`) เพื่อช่วยเป็นแสงสว่างส่องใบหน้า (Screen Fill Light) ช่วยให้ภาพสว่างคมชัด
4. **เก็บครบ 12 ท่าทาง:** มีกรอบวงรีนำทางใบหน้า พร้อมแนะนำทีละท่าทาง (หน้าตรง, ยิ้ม, ขยับปาก, ระยะใกล้, หันซ้าย 15°/30°, หันขวา 15°/30°, เงยหน้า, ก้มหน้า, เอียงคอ, และรอบแสงสะท้อน)
5. **จัดเก็บเป็นระเบียบบน Google Drive:** รูปภาพจะถูกสร้างเป็นโฟลเดอร์แยกตามชื่อคน เช่น:
   ```text
   Google Drive / Face_Dataset /
   └── สมชาย_ใจดี_20261113_150000/
       ├── 01_frontal_neutral.jpg
       ├── 02_frontal_smile.jpg
       ├── 03_frontal_expression.jpg
       ├── 04_frontal_scale.jpg
       ├── 05_yaw_left_15.jpg
       ├── 06_yaw_left_30.jpg
       ├── 07_yaw_right_15.jpg
       ├── 08_yaw_right_30.jpg
       ├── 09_pitch_up_15.jpg
       ├── 10_pitch_down_15.jpg
       ├── 11_roll_or_glasses.jpg
       ├── 12_screen_warm_light.jpg
       └── metadata.json
   ```
6. **พร้อมนำไปเทรนโมเดลในอนาคต:** สามารถเปิด Google Colab แล้วสั่ง `drive.mount('/content/drive')` เพื่อดึงภาพไปเทรนโมเดล ArcFace / GhostFaceNets / MobileFaceNet ได้ทันที

## 🚀 วิธีติดตั้งและเปิดใช้งาน (ใช้เวลาเพียง 2 นาที)

### ขั้นตอนที่ 1: สร้างโปรเจกต์ Google Apps Script
1. เปิดเบราว์เซอร์แล้วเข้าไปที่ [script.new](https://script.new) (หรือเข้า Google Drive -> กด **+ ใหม่** -> **เพิ่มเติม** -> **Google Apps Script**)
2. ตั้งชื่อโปรเจกต์ที่มุมซ้ายบน เช่น `Face Dataset Collector`

### ขั้นตอนที่ 2: วางโค้ด `Code.gs`
1. ในแถบไฟล์ด้านซ้าย จะมีไฟล์ชื่อ `Code.gs` อยู่แล้ว ให้ลบโค้ดเดิมออกทั้งหมด
2. เปิดไฟล์ [Code.gs](file:///d:/get_data_set/Code.gs) ในโฟลเดอร์นี้ คัดลอกโค้ดทั้งหมดแล้วนำไปวางในช่อง `Code.gs` บนเว็บ

### ขั้นตอนที่ 3: เพิ่มไฟล์ `Index.html`
1. ในแถบไฟล์ด้านซ้าย กดปุ่ม **+** (เพิ่มไฟล์) -> เลือก **HTML**
2. ตั้งชื่อไฟล์ว่า `Index` (ไม่ต้องใส่นามสกุล `.html`)
3. เปิดไฟล์ [Index.html](file:///d:/get_data_set/Index.html) ในโฟลเดอร์นี้ คัดลอกโค้ดทั้งหมดแล้วนำไปวางแทนที่โค้ดเดิมในไฟล์ `Index.html` บนเว็บ
4. กดรูป **แผ่นดิสก์ (บันทึกโปรเจกต์)** หรือกด `Ctrl + S`

### ขั้นตอนที่ 4: เผยแพร่เป็นเว็บแอป (Deploy as Web App)
1. กดปุ่มสีน้ำเงิน **"ทำให้ใช้งานได้" (Deploy)** ที่มุมขวาบน -> เลือก **"การทำให้ใช้งานได้รายการใหม่" (New deployment)**
2. กดรูปเฟือง ⚙️ ด้านซ้าย เลือกประเภทเป็น **"เว็บแอป" (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `v1.0`
   - **ดำเนินการในฐานะ (Execute as):** **"ฉัน" (Me - อีเมลของคุณ)** *(สำคัญมาก เพื่อให้สิทธิ์ในการเซฟไฟล์ลง Google Drive ของคุณ)*
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **"ทุกคน" (Anyone)** *(สำคัญมาก เพื่อให้เพื่อนๆ เปิดเว็บเข้ามากดถ่ายได้เลยโดยไม่ต้องล็อกอินบัญชี Google ซ้ำ)*
4. กดปุ่ม **"ทำให้ใช้งานได้" (Deploy)**
5. ในการเปิดใช้งานครั้งแรก ระบบ Google จะขอให้อนุญาตสิทธิ์การเข้าถึง Drive:
   - กด **"ให้สิทธิ์การเข้าถึง" (Authorize access)** -> เลือกบัญชี Google ของคุณ
   - หากมีหน้าต่างเตือน *"Google ยังไม่ได้ยืนยันแอปนี้"* ให้กดที่คำว่า **"ขั้นสูง" (Advanced)** ด้านล่าง แล้วกด **"ไปที่ Face Dataset Collector (ไม่ปลอดภัย)"**
   - กด **"อนุญาต" (Allow)**
6. คุณจะได้รับ **URL เว็บแอป (Web App URL)** เช่น:
   ```text
   https://script.google.com/macros/s/AKfycbx.../exec
   ```
